## 🚀 Featured Projects

### 🛢️ OilGuard

**AI-powered offshore environmental monitoring platform**

Satellite-based oil spill detection and segmentation using Sentinel-1 SAR imagery, combined with geospatial analysis, offshore infrastructure data and automated risk assessment.

**Stack:** PyTorch • DeepLabV3+ • FastAPI • Next.js • GeoPandas • Rasterio • WebSockets

🔗 [Repository](https://github.com/arbiahani2-wq/oil-guard)
🌐 [Live Demo](https://oil-guard.vercel.app/)

---

### 🧬 GenoPredict AD

**Machine Learning & Bioinformatics prototype**

A web application combining genomic data processing, Mendelian inheritance simulation and a Random Forest model to explore polygenic risk estimation.

**Stack:** Python • Scikit-learn • Flask • React • Docker

🔗 [Repository](https://github.com/arbiahani2-wq/genopredict)
🌐 [Live Demo](https://genopredict.vercel.app/)
